# Science Companion

A one-page static coaching app that helps a parent support an 8th-grade science student at Bush School. It's a coaching and understanding helper, not a homework-answer generator, and it respects the class Green/Yellow/Red AI policy.

## Use

Just open `index.html` in a browser. No install, no build step. (You can also deploy it to Vercel for a shareable link.)

## Deploy to Vercel

It's a static site, so there's no build step or config needed. Either:

- Connect this GitHub repo in the [Vercel dashboard](https://vercel.com/new), or
- Run `vercel` from the project directory.
